# P1-1 Explore 验收流程

## 自动化门禁

在仓库根目录执行：

```powershell
.\gradlew.bat :shared:testDebugUnitTest :androidApp:testDebugUnitTest :androidApp:assembleDebug --no-daemon
```

HarmonyOS 环境可用时继续执行 shared arm64 编译、ohosApp 测试与 HAP 构建。环境缺失时不得把 HarmonyOS 标记为已验收。

## 双端手工验收

1. 从探索首页进入“探索地点”，确认搜索框紧接顶栏并位于分类和结果之前。
   向下滚动长列表，顶栏、搜索框和分类 chips 必须持续可见；搜索框不得再出现独立“搜索”标题，图标和 placeholder/输入文字应位于同一视觉中线。
2. 横向滑动分类 chips；分别选择单个、多个分类及“全部”，确认结果、选中态和返回详情后的筛选状态正确。
3. 点击“筛选”，确认城市、区域和“只看想去”只出现在 Bottom Sheet；应用、清除和关闭后结果正确，首屏没有大表单堆叠。
4. 点击地点行的非心形区域，确认进入对应 typed `PlaceDetail(placeId)`；点击心形只改变想去状态，不进入详情、不重排当前列表、不丢搜索/筛选/滚动位置。
5. 确认 Explore 首屏没有“查看详情”按钮或“新建地点”大 CTA；“新建地点”仅在右上角更多菜单中。空 catalog 时允许空态提供辅助新建入口。
6. 进入“想去的地方”，确认它使用搜索、地点内容行与整行详情入口，而非编辑/删除管理列表；移出想去后该行即时消失。不得出现“最近想去”排序文案。
7. 在没有定位权限和定位实现的当前版本，确认页面只显示“档案城市优先 · 本地点目录”或“本地点目录”，全页不出现“附近”、距离、当前位置或权限请求。修改档案城市后重新进入，确认同城地点稳定优先，但其他本地目录地点仍可浏览。
8. 覆盖 Loading、无 catalog、想去为空、无匹配结果、只读恢复和想去读写失败；失败不得模拟成功，写操作在只读状态必须禁用。
9. 在 Android 与 HarmonyOS 分别检查 Light/Dark、大字体、窄屏、返回栈、长列表滚动、Bottom Sheet 和更多菜单位置；确认心形触控不会冒泡为整行导航。
   Bottom Sheet 的标题和完成/关闭操作保持可见，只有中部筛选内容滚动；打开键盘后不得遮住完成操作。
10. 反复进入/退出页面并切前后台，确认 Load 不因重组重复触发、Effect 不重复导航、页面销毁后无延迟状态更新或导航。

## HarmonyOS 增量列表性能验收（2026-09-02）

使用同一设备、刷新率、城市、关键词和网络条件，固定每页 12 条，至少连续加载 3 页；冷启动首次结果与缓存命中结果分别执行 5 次。测试时记录构建版本、设备温度和是否清理图片缓存。

1. 用 HiSmartPerf/DevEco Profiler 采集分页返回前后各 2 秒的 FPS、FPS jitter、滑动卡顿率和最大连续丢帧；60/90/120 Hz 的单帧预算分别为 16.67/11.11/8.33 ms。
2. 用外部 120 fps 以上录像选择分页前屏幕中央的 `providerId` 作为锚点，测量分页完成前后屏幕 Y 坐标；目标为旧地点不换位，锚点漂移不超过 2 dp。
3. 首页稳定后不滑动，确认不会连续请求 page 2/3；滑到倒数 3 个在线地点时只请求一次下一页。连续快速滑动也不得并发或重复请求同一页。
4. 分页成功后确认旧 ID 序列仍是新序列的完整前缀；跨页 provider ID 无重复，图片不串行、不闪成其他地点。
5. 分页过程中切换关键词、主题或城市，让旧请求最后返回；页面只能展示新上下文结果。旧响应不得覆盖或追加。
6. 在下一页断网时旧地点保持可浏览，固定 Footer 显示“加载失败，点击重试”；恢复网络点击后只重试该页。Loading/失败/末页切换不应推动可见地点。
7. 分别以“仅类别 fallback”和“真实在线图片”执行，区分列表布局抖动与图片解码/原生节点成本。若只有真实图片下降，继续采集图片 adapter 与 Render Service trace，不回退 Lazy 结构。

建议使用表格保存优化前/后实测值：平均 FPS、P95/P99 帧耗时、最大连续丢帧、滑动卡顿率、锚点位移、各页请求次数。没有真机数据时不得声称性能提升百分比。

## 通过标准

自动化全部通过，且上述双端设备检查无阻断问题后，才把 P1-1 从“代码完成/设备 Partial”更新为 DONE。真实摄影、定位、地图、距离和外部导航不属于本验收范围。
