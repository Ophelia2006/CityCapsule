# CityCapsule Information Architecture（Proposal）

> 已确认的信息架构基线；目标结构不代表页面均已实现。当前实现与目标差异以 `CURRENT_STATE.md` 为准。

## 1. 设计原则

- 一级导航固定为“探索 / 记录 / 漫游 / 我的”；漫游只展示真实路线、活动会话和历史。
- 地图是探索的查看方式，不是一级 Tab。
- 真实内容单元（地点、碎片、照片）可使用 Card；设置、筛选、说明文字不用 Card 包装。
- 未实现能力不进入正式入口；已落地的平台能力在失败、拒绝或无 Key 时必须诚实降级。

### 探索列表与地图探索的明确入口

```text
底部导航「探索」
  → 探索首页
     ├─ 点击搜索框 → 探索列表（自动聚焦搜索）
     ├─ 点击分类 → 探索列表（携带对应分类筛选）
     ├─ 点击「查看全部地点」 → 探索列表（无筛选）
     └─ 点击重点地点/地点摘要 → 地点详情

探索列表
  ├─ 顶部「列表 / 地图」状态切换 → 同一探索容器内显示地图
  └─ 点击地点行 → 地点详情

地图视图
  ├─ 顶部「列表 / 地图」状态切换 → 同一探索容器内恢复列表并保留搜索/筛选
  └─ 点击 marker 后的地点摘要 → 地点详情
```

- **探索列表没有独立底部 Tab**，它是探索首页的二级页。
- **地图探索没有独立底部 Tab，也不直接出现在探索首页**；它只作为探索容器的另一种查看方式。列表/地图切换不执行页面 push、replace 或 back。
- 双端高德地图、坐标、定位和 marker 已接入；正式入口已开放。权限拒绝、无 Key、网络或初始化失败时保留列表降级，完整异常矩阵仍待双端真机留证。
- 地图不可用、权限被拒绝或初始化失败时，停留/返回探索列表，不进入空白地图页。

### 导航状态与页面栈规则

#### Current Architecture（P0-3A）

- 四个真实根目标固定为“探索 → Home / 记录 → Record / 漫游 → Roam / 我的 → Profile Overview”，全部位于同一 `AppShellPage`。
- Bottom Navigation 只有一个结构实例；点击其他 Tab 调用根 `PagerState.scrollToPage` 即时切换，重复点击为 no-op。根 Pager `userScrollEnabled=false`，暂不提供手指左右滑动。
- Home/Timeline/Profile typed route 仍存在，但统一解析到 canonical `app_shell`，以 `initialRootTab` 选择初始页；壳内 Tab 切换不调用 dispatcher，不改变原生返回栈。
- 四个根内容持续组合并分别保存滚动、筛选/编辑等页面状态；RecordRootView 也由 AppShell 持有。
- 地点详情、碎片详情、编辑器、设置等二级目标继续进入导航栈，并隐藏底栏。

#### Record Container（部分实现）

- “时间轴 / 相册”已经是同一个 RecordRootContent 内的两种 Compose 视图，共享底栏、catalog 加载结果和 RecordRootView。
- 当前以 segmented control 点击切换，不执行 `push`、`replace` 或 `back`；内部 `HorizontalPager` 与左右滑动是 P0-3B 未完成项。
- 进入碎片详情时才使用 typed route；返回后恢复原 Record 视图。现有独立 `Gallery` route/page 在迁移和兼容测试完成前保留，但不再代表目标 IA。

#### Future Gesture Evaluation

- 单一 AppShell 与状态保留已实现。是否把根 Pager 的 `userScrollEnabled` 改为 `true`，必须在 Record 内部 Pager 完成后单独评估同轴手势冲突；当前不得提前开放。

### 地点图片规则

- 探索首页、地点列表、想去和地点详情必须优先显示地点对应的真实图片；不得使用 `▧`、Emoji 或无来源假照片代替。
- 当前 `Place` 已有 `visualRef`、来源与远程照片缓存链路；用户地点可使用托管封面，高德在线地点可显示来源明确的远程照片。内置 seed 仍没有已登记摄影，继续使用代码生成的类别 fallback。
- 图片加载失败属于单个内容单元的 Partial Data：保留地点文字与点击能力，图片区域回退到类别 fallback，不把整页切换为 Error。

## 3. 页面定义

| 页面 | 目标/来因 | 核心内容 | Primary CTA | 次级动作 | 上一页 → 下一页 | 层级 |
| --- | --- | --- | --- | --- | --- | --- |
| 探索首页 | 回答今天可探索什么 | 本地规则选出的重点地点、分类、最近碎片 | 打开重点地点（整卡） | 搜索框/分类/“查看全部地点”进入探索列表；想去、最近记忆 | 启动 → 列表/详情 | 一级 |
| 地点列表 | 找到一个本地地点 | 搜索、分类、真实 catalog | 打开地点（整行） | 筛选、清除；地图能力完成后由顶部视图切换进入地图；新建在溢出 | 探索首页 → 详情/地图 | 二级 |
| 想去 | 回看已标记地点 | favorite 与 catalog 交集 | 打开地点 | 搜索/移出想去 | 首页/我的 → 详情 | 二级 |
| 地图探索 | 空间查看地点 | marker、列表摘要、权限降级 | 打开地点 | 定位、切回列表 | 探索列表 → 详情/探索列表 | 二级查看方式，代码已实现、设备异常矩阵待关闭 |
| 地点详情 | 决定是否记录或想去 | 地点信息、关联碎片摘要 | 留下城市碎片 | 想去、关联记忆；管理进菜单 | 列表 → 编辑器 | 详情 |
| 地点编辑 | 维护本地地点 | 表单与校验 | 保存地点 | 放弃 | 列表/详情 → 详情 | 操作 |
| 碎片编辑 | 留下一刻 | 照片、正文、心情、标签、地点 | 保存到城市记忆 | 保存草稿 | 地点/详情 → 碎片详情 | 操作 |
| Record / 时间轴 | 按时间回忆 | 日期、地点、碎片摘要 | 打开碎片（整卡） | 容器内切换相册 | Tab/详情 → 碎片详情 | 一级根容器视图 |
| Record / 城市相册 | 从照片回忆 | 照片网格 | 打开照片所属碎片 | 容器内切换时间轴 | 记录 → 碎片详情 | 一级根容器视图 |
| 碎片详情 | 阅读一条记忆 | 照片、日期、正文、心情、标签、地点 | 查看关联地点 | 编辑；删除进菜单 | 时间轴/相册 → 地点 | 详情 |
| 漫游 | 决定并继续一次城市探索 | 想去联动路线、活动会话、最近回顾 | 开始/继续真实漫游 | 路线管理、历史 | Tab → 会话/路线/回顾 | 一级 |
| 我的城市档案 | 理解自己的本地城市记录 | 档案、碎片数、关联地点数、想去数、想去入口、设置入口 | 编辑档案 | 想去、设置 | Tab → 编辑/想去/设置 | 一级 |
| 设置 | 调整应用偏好 | 主题、引导、危险操作 | 无全局 Primary | 主题选择、重看引导 | 我的 → 子项 | 二级 |

## 4. 视觉优先级

| 页面 | Primary | Secondary | Tertiary |
| --- | --- | --- | --- |
| 探索首页 | 今日地点与探索入口 | 分类、想去、最近记忆 | 城市/头像 |
| 地点列表 | 搜索结果与地点 | 分类/筛选 | 新建地点、重载 |
| 地点详情 | 地点身份与记录 CTA | 想去、地址、关联碎片 | 编辑、删除 |
| 碎片编辑 | 正文/照片与发布 | 心情、标签、草稿 | 关闭 |
| 时间轴/相册 | 真实碎片/照片 | 视图切换 | 返回/辅助说明 |
| 碎片详情 | 记忆内容 | 关联地点 | 编辑、删除 |
| 我的 | 档案与真实记录计数 | 想去、设置 | 清除档案 |

## 5. 当前与目标差异

- 原计划中的地图、导航和导入导出已形成代码链路；当前差距是双端真机异常矩阵与当前机器 HarmonyOS 复建，不再是功能空壳。
- 当前 Home 已移除技术信息并接入正式探索根导航，但内容仍只有地点/想去入口；目标 Home 消费本地 Place/Capsule/Favorite 数据。
- 当前 Profile 只是本地身份；目标“我的城市档案”若展示统计，只能从现有 catalog 实时计算，不能虚构足迹或里程。
- 首页本地排序允许 seed 与用户自建地点混合参与；当前模型没有 source，排序不得伪装成能够区分来源。
- 地点摄影能力完成前统一使用代码生成的类别 fallback；不得为满足草图硬编码假照片。
