# P1-4 大屏与可访问性验收

## 代码边界

- 已实现：Explore 地点列表/地点信息双栏、Record 时间轴/碎片阅读双栏、Editor 640dp 可读宽度、共享 `AdaptivePane`、核心操作语义、48dp 触控基线、浅色主按钮对比度修正、根 Tab 无位移动画。
- 未实现：真实 Map/地点信息。当前缺坐标、定位、地图 Native View 与双端 SDK；本轮仅保证 `AdaptivePane` 可承载该形态，不建立假地图入口。

## 自动化

1. 在仓库根目录运行 `.\gradlew.bat :shared:testDebugUnitTest`。
2. 运行 `.\gradlew.bat :shared:compileDebugKotlinAndroid`。
3. 运行 `git diff --check`，不得出现空白错误。

## 大屏

在 Android 平板/可调整大小模拟器与 HarmonyOS 大屏设备分别执行：

1. 宽度小于 600dp：Explore 点击地点进入独立详情；Record 点击碎片进入独立详情；不出现被截断的空白副 pane。
2. 宽度达到或超过 600dp：Explore 左侧地点目录、右侧地点信息同时存在；选择不同地点只更新右 pane，“打开地点详情”仍进入完整 typed detail。
3. Record 时间轴在左、碎片阅读区在右；切换条目只更新右 pane，“打开城市碎片”进入完整详情。
4. 从横屏切竖屏再切回，搜索/筛选、当前 Record 视图与可恢复业务数据不丢失；允许当前仅由 Compose 保存的 pane 选择回到首项。
5. Capsule Editor 与 Place Editor 在 1200dp 宽窗口中内容列不超过 640dp，居中且两侧留白；软键盘不遮挡当前输入。
6. Map 只检查“正式 UI 无空壳入口”。真实地图双栏验收推迟到 Map Feature。

## 大字体与触控

1. 系统字体分别设为默认、1.3x、最大档；检查顶栏、搜索、Chip、底栏、编辑器和双栏详情。
2. 文本不得重叠或被固定高度裁切；Bottom Navigation 可以增高，三个 Tab 仍完整可读。
3. 使用布局检查器或手工点击边缘确认按钮、图标按钮、底栏 Tab 的触控区域至少 48×48dp。
4. 长地点名、长城市/区域名、500 字碎片正文与 8 个标签不遮挡主要 CTA。

## 屏幕朗读与语义

1. Android 开启 TalkBack，HarmonyOS 开启屏幕朗读。
2. 焦点依次遍历页面标题、搜索、筛选、内容项、主操作和底栏；不得朗读无意义的图标字形。
3. 图标按钮朗读动作名；Bottom Navigation 朗读“探索/记录/我的”、Tab 角色与“已选择/未选择”。
4. 双栏分别具有“地点列表/地点信息”或“时间轴/城市碎片详情”pane 名称。
5. 图片朗读地点或城市记忆含义；装饰性图标不重复朗读。

## 对比与减少动效

1. Light 主题主按钮 `#A85F16`/白字对比度约 4.87:1；正文和次级文字按 token 抽查，正常文本至少 4.5:1。
2. Dark 主题重复抽查；错误、成功、想去选中必须同时有文字/图标或状态描述，不能只靠颜色。
3. 快速切换三个根 Tab：页面直接切换，不播放横向滑行动画；重复点击当前 Tab 无动作。
4. Bottom Sheet、系统页面转场属于平台/组件剩余动效，本轮不得新增循环、视差或装饰性动画。

## 通过标准

- shared 自动化与 Android 编译通过。
- Android 与 HarmonyOS 各完成一次手机和大屏走查。
- 无 P0/P1 级裁切、不可达操作、错误朗读或对比度失败。
- Map 项保持明确未实现，不因自适应容器存在而标记 DONE。
