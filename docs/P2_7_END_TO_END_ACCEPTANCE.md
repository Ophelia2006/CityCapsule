# P2-7 路线、漫游、轨迹、打卡与总结：双端总验收

> 本文创建时“漫游”尚未进入一级导航。ADR-036 已在真实闭环落地后批准第四个 Tab；本文功能矩阵仍有效，但“验收后才评估 Tab”的旧门槛已失效。

在 Android 和 HarmonyOS 各完整执行一次；任一平台失败都不能评估增加“漫游”一级 Tab。

## 1. 选择路线（7A）

1. 探索 → 我的路线 → 新建路线，选择至少两个带真实坐标的地点并排序。
2. 保存、重启、再次打开，确认名称和顺序一致。

## 2. 开始与恢复漫游（7B）

1. 从该路线点击“按此路线开始漫游”。
2. 验证开始 → 暂停 → 重启 App → 继续；会话状态和路线关联不丢失。

## 3. 前台持续定位与轨迹（7C）

1. 漫游页保持前台并允许定位，实际移动；至少产生三个轨迹点和三个沙箱分片。
2. 暂停或离开页面时不采样，继续/返回后恢复。
3. 关闭定位触发中断，确认漫游未结束；恢复后重试成功。

## 4. 到达与打卡（7D）

1. 到达路线地点 150 米以内，等待采样；页面出现“确认到达”，由用户点击后记录 `GPS_CONFIRMED`。
2. 在未进入附近范围时不得提供 GPS 确认，不得自动打卡。
3. 关闭定位后，对另一地点使用“手动记录”；总结必须明确区分“手动记录”，不得显示为 GPS 到达。
4. 当前版本不应出现扫码入口。

## 5. 城市碎片

1. 已打卡地点点击“在这里留下城市碎片”。
2. 完成一条带该地点 ID 的真实城市碎片并返回漫游。

## 6. 结束与真实总结

1. 结束漫游，确认总结展示：经过地点、打卡地点、真实开始/结束时间、轨迹距离、关联城市碎片数量。
2. 轨迹距离应由分片中的连续真实点累计；无足够点时显示“无法计算”，不得用路线点间距离代替。
3. 重启后重新进入，确认总结仍可从持久数据重建。

## 7. 数据边界

1. MMKV 中只有 session、分片索引、打卡与状态元数据；坐标点位于 `files/tracks`。
2. 导出/导入 v6 备份后索引与打卡元数据恢复；轨迹文件必须随备份媒体策略另行核验。旧版本备份缺失新 key 时安全迁移为空。
3. 当前底栏始终只有“探索 / 记录 / 我的”。完成两端所有步骤并记录证据后，才创建单独产品决策评估“漫游”Tab。

## 8. 2026-08-24 新增：想去联动

1. 先将 A、B 加入“想去”，C 不加入。从想去页点击“规划漫游”，路线选点中 A、B 应优先且带想去标识。
2. 确认到达 A，A 应从想去移除；点击撤销后 A 应恢复。重复确认不得产生重复 CheckIn。
3. 自由漫游的 500 米附近列表中，想去地点应优先展示；无坐标/定位失败时必须诚实降级。

## 9. 2026-08-24 新增：持久回顾

1. 结束漫游后点击“查看漫游回顾”，确认地点顺序、到达时间/方式、真实距离和关联 Capsule 正确。
2. 已有 Capsule 的到达项应打开详情；无 Capsule 的到达项应显示“补记这一刻”，完成后与当前地点和漫游 ID 关联。
3. 从“记录 → 漫游回顾”进入列表，本次记录应在首位。杀进程并重启后，历史及 Capsule 关联不得丢失或重复。
4. 会话活动时从另一路线/自由漫游尝试开始，必须引导继续现有会话，不得覆盖。在“结束→归档”窗口强杀并重启，已结束会话应补归档且不重复。

## 10. 双端异常矩阵

- 定位：允许、拒绝、永久拒绝/设置恢复、系统定位关闭、超时；单次失败不得自动结束漫游。
- 生命周期：页面反复进出 20 次、前后台、暂停后杀进程、结束时强杀。
- 媒体：相册/相机取消、读取失败、低存储空间、重启后回退与引用保护清理。
- 数据：从旧版覆盖升级；导出 v10 后清除并导入，确认路线、想去、Capsule、历史和媒体关联恢复；损坏/超大/未来版本包必须在覆盖前失败。
- 轨迹：无网/弱网、分片读取失败时不得用路线直线距离冒充 GPS 距离。

每端留存 commit、包时间、设备/系统版本、录屏/截图、日志与失败问题 ID。任一核心步骤失败都保持 `PARTIAL`，不得只以页面可打开标记 DONE。

## 11. 实时地图与创建碎片选点

1. 开始漫游后不同意地图展示，确认页面可继续轨迹采样；再主动打开并同意，地图应显示当前位置、路线/附近地点 Marker 和暖橙色已走轨迹。
2. 实际移动至少 5 分钟，每次新采样后折线应延长且地图跟随最新位置；暂停后不再增长，继续后恢复。
3. 杀进程并重启后继续会话，打开地图应从轨迹分片恢复旧折线，新点继续追加而非清空。
4. 在当前景点 200 米内点击“留下城市碎片”，选点 Sheet 默认项应是当前最近景点；改选另一附近/路线/已到达地点后创建，最终 Capsule 的 `placeId` 必须是改选值，`roamingSessionId` 仍是本次会话。
5. 无附近点、无路线点且无已到达点时，选点 Sheet 必须诚实显示无可关联地点，不得用虚构地点创建。
6. 分别验收 Android/HarmonyOS 无 Key、断网、SDK 初始化失败和地图页面反复进出 20 次；地图失败必须提示降级，不得中断已授权的本地轨迹记录。
7. 当前版本另行记录锁屏、长时后台和系统回收下的缺口；后台定位 Feature 完成前不将这三种情况标记为已验收。
