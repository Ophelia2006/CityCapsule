# P2-7B 漫游会话验收

## 当前边界

- `RoamingSession` 仅保存可选 `routeId`、`startedAtEpochMs`、可选 `endedAtEpochMs` 和 `status`。
- 状态机只允许：开始（ACTIVE）→ 暂停（PAUSED）→ 继续（ACTIVE）→ 结束（ENDED）。进行中或暂停时也可直接结束。
- 支持绑定一条仍存在的本地路线，或从路线列表选择“自由漫游”。
- 不请求定位权限，不采集 GPS，不生成轨迹，不判断到达，不打卡，不增加一级 Tab。


## Android / HarmonyOS 手工流程

1. 确认底栏仍只有“探索 / 记录 / 我的”。
2. 探索 → 我的路线 → 自由漫游，确认初始页只显示“开始漫游”。
3. 点击开始，确认状态为进行中，只显示“暂停漫游”和“结束漫游”。
4. 点击暂停，确认状态为已暂停，主操作变为“继续漫游”。
5. 完全结束 App 进程后重启，重新进入自由漫游，确认仍为已暂停。
6. 点击继续，确认恢复进行中；再结束，确认状态为已结束且不能继续旧会话。
7. 新建或打开一条本地路线，点击“按此路线开始漫游”，确认页面显示路线名称并可完成同一状态循环。
8. 在漫游进行中直接点击结束，确认允许结束。
9. 断网重复以上流程，应完全可用；过程中不应出现定位权限申请。
10. 导出备份，改变会话后再导入，确认会话状态恢复；导入 v3 备份应成功且没有旧漫游会话。

## 失败与边界验收

- 已结束会话不能暂停或继续；暂停状态不能再次暂停。
- 路线已不存在时，绑定路线的“开始漫游”不可用。
- 页面不得显示距离、速度、轨迹、当前位置、途经点到达或打卡成功。
